## protocol
MAGIC = b"IRLK" ⇒ Four letters that start every message, to detect a stream out of step.
HEADER = struct.Struct("<4sBxxxqI") ⇒ The 20-byte header: 4 letters, 1-byte kind, 3 padding bytes, 8-byte time, 4-byte length.
CLOCK = 1 ⇒ Kind 1: clock. No payload.
IMU = 2 ⇒ Kind 2: IMU, 10 doubles.
LIDAR = 3 ⇒ Kind 3: LiDAR: a count, then the points.
IMAGE = 4 ⇒ Kind 4: image: width, height, then pixels.
TRUTH = 5 ⇒ Kind 5: ground truth, 10 doubles.
VECTOR10 = struct.Struct("<10d") ⇒ Layout of ten doubles (80 bytes).
COUNT = struct.Struct("<I") ⇒ Layout of one 4-byte count.
SIZE = struct.Struct("<HH") ⇒ Layout of two 2-byte numbers: width, height.
ACK = struct.Struct("<Q") ⇒ Layout of the 8-byte acknowledgement count.
LIDAR_POINT_BYTES = 20 ⇒ Each LiDAR point is 20 bytes.
def pack(kind, time_ns, payload=b""): ⇒ Defines pack(): make one message.
return HEADER.pack(MAGIC, kind, time_ns, len(payload)) + payload ⇒ The header, then the payload.
def read_exact(stream, size): ⇒ Defines read_exact(): read exactly size bytes from a socket.
data = bytearray() ⇒ Start empty.
while len(data) < size: ⇒ Until there are enough:
chunk = stream.recv(size - len(data)) ⇒ read what is missing (TCP may hand over less);
if not chunk: ⇒ nothing means the other side closed…
raise EOFError ⇒ …so report end of stream;
data += chunk ⇒ add what arrived.
return bytes(data) ⇒ Give back the bytes.
def read_message(stream): ⇒ Defines read_message().
magic, kind, time_ns, length = HEADER.unpack(read_exact(stream, HEADER.size)) ⇒ Read 20 bytes and split the header.
if magic != MAGIC: ⇒ If it does not start with IRLK…
raise ValueError("stream out of sync") ⇒ …the stream is out of step: fail.
return kind, time_ns, read_exact(stream, length) ⇒ Read the payload and give back all three.
def finish(stream): ⇒ Defines finish(): end a stream.
stream.shutdown(socket.SHUT_WR) ⇒ Close our sending side (the reader sees end of stream).
return ACK.unpack(read_exact(stream, ACK.size))[0] ⇒ Read the reader's 8-byte count and give it back.
